# Data Science and Machine Learning Journey

A structured learning repository covering Data Science, Machine Learning, and MLOps through theory, Python programming, practical implementations, exercises, interview preparation, and end-to-end projects.

## About This Repository

This repository documents my learning journey from Python programming fundamentals to advanced Machine Learning concepts and MLOps.

It is designed to serve as a centralized resource for learning, practicing, revising concepts, and preparing for technical interviews.

The repository follows a topic-wise and progressive structure to make concepts easier to understand and revisit.

## Learning Roadmap

### 1. Python Programming
- Python fundamentals, data types, variables, and operators
- Conditional statements, loops, and strings
- Lists, tuples, sets, and dictionaries
- Functions, lambda functions, and comprehensions
- Object-Oriented Programming (OOP)
- File handling, exception handling, decorators, iterators, and generators
- Time and space complexity

### 2. NumPy
- NumPy arrays and matrices
- Array attributes and operations
- Indexing, slicing, and broadcasting
- Mathematical and statistical operations
- Reshaping, stacking, and splitting

### 3. Pandas
- Series and DataFrames
- Data selection, filtering, and manipulation
- Missing-value handling and duplicate removal
- GroupBy, merging, joining, and concatenation
- Datetime and string operations
- Practical data analysis case studies

### 4. Data Visualization
- Matplotlib
- Seaborn
- Plotly and Dash
- Interactive dashboards
- Tableau and Power BI

### 5. Data Analysis
- Data gathering and assessment
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Univariate and multivariate analysis
- Feature engineering
- Data analysis case studies

### 6. SQL and Databases
- Database fundamentals and SQL commands
- Filtering, grouping, and sorting
- Joins and subqueries
- Window functions
- Transactions and stored procedures
- Database design and normalization
- SQL-based data cleaning and analysis

### 7. Statistics, Probability, and Linear Algebra
- Descriptive and inferential statistics
- Probability and probability distributions
- Normal, binomial, and other distributions
- Central Limit Theorem
- Confidence intervals and hypothesis testing
- Correlation, covariance, and regression statistics
- Vectors, matrices, eigenvalues, eigenvectors, and SVD

### 8. Machine Learning
- Machine Learning fundamentals and lifecycle
- Linear and polynomial regression
- Gradient Descent and optimization
- Regression analysis and evaluation metrics
- Feature selection and regularization
- K-Nearest Neighbors (KNN)
- Principal Component Analysis (PCA) and SVD
- Naive Bayes, Logistic Regression, and SVM
- Decision Trees and ensemble methods
- Random Forest and Gradient Boosting
- XGBoost, LightGBM, and CatBoost
- Clustering and dimensionality reduction
- Model evaluation, cross-validation, and hyperparameter tuning

### 9. Feature Engineering and ML Pipelines
- Missing-value imputation
- Categorical feature encoding
- Feature scaling and transformation
- Outlier detection
- Feature selection
- Scikit-learn transformers and pipelines

### 10. MLOps
- Git and GitHub
- Reproducible ML workflows
- Cookiecutter and project packaging
- Data Version Control (DVC)
- MLflow and experiment tracking
- Docker and containerization
- Continuous Integration and Continuous Deployment (CI/CD)
- FastAPI and model deployment
- AWS services
- Kubernetes and model monitoring
- Model rollout and rollback strategies

### 11. Projects
- Exploratory Data Analysis projects
- SQL case studies
- Interactive visualization dashboards
- Machine Learning model implementations
- End-to-end Machine Learning applications
- MLOps and deployment projects
