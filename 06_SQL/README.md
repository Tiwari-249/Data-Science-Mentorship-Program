## Learning Objectives

- Understand databases, DBMS concepts, keys, and relationships.
- Write SQL queries for creating, retrieving, updating, and deleting data.
- Use DDL and DML commands effectively.
- Filter, sort, group, and aggregate data.
- Work with joins, set operations, and subqueries.
- Apply window functions for ranking and analytical calculations.
- Clean and explore datasets using SQL.
- Solve practical SQL problems using IPL, Zomato, and laptop datasets.
- Connect MySQL with Python and build interactive dashboards.
- Create dashboards and visualizations using Tableau.
