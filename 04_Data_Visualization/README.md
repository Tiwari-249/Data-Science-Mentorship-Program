## Learning Objectives

- Create basic and advanced visualizations using Matplotlib.
- Customize plots with labels, legends, annotations, and subplots.
- Create interactive visualizations using Plotly.
- Build dashboards using Plotly Dash.
- Understand the basics of deploying dashboard applications.
- Perform statistical and categorical visualization using Seaborn.
- Create distribution, regression, and relational plots.
- Use multi-plot grids to explore relationships between variables.
- Visualize real-world datasets, including COVID-19 and Indian Census data.
