## Learning Objectives

- Create different types of plots using Matplotlib.
- Customize visualizations with labels, legends, annotations, and styles.
- Create advanced visualizations, including 3D plots, contour plots, and heatmaps.
- Visualize Pandas DataFrames using the `plot()` method.
- Understand Plotly Express and Plotly Graph Objects.
- Build interactive dashboards using Dash.
- Develop a COVID-19 data visualization dashboard.
- Deploy a Dash application on Heroku.
- Visualize Indian Census data using Plotly and geospatial indexing.
