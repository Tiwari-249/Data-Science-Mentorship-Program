## Learning Objectives

- Understand the data analysis process.
- Import and export data in different formats.
- Gather data using APIs and web scraping.
- Assess data quality and identify unclean data.
- Apply manual and automatic data assessment techniques.
- Clean datasets by addressing quality and tidiness issues.
- Understand ETL pipelines and data integration with AWS RDS.
- Perform automated web scraping using Selenium.
- Conduct univariate and bivariate exploratory data analysis.
- Apply feature engineering techniques during data analysis.
