## Learning Objectives

- Understand the data analysis process.
- Import and export data in different file formats.
- Gather data using APIs and web scraping.
- Assess data quality and identify unclean data.
- Perform manual and automatic data assessment.
- Identify data quality issues and prepare datasets for analysis.
- Understand the ETL pipeline and its stages.
- Fetch, transform, and upload data using AWS RDS.
- Automate web scraping using Selenium and ChromeDriver.
- Practice web scraping using the Smartprix website.
